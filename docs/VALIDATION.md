## 复现

1. 按 README 安装实际技能，并在目标客户端确认名称可识别。
2. 使用 `evals/scenarios.md` 中的输入进行盲测；向被测助手提供输入与技能，不先提供检查标准。
3. 保存原始回答，再按标准人工评价；不要用标题、字数或相同结论代替行为正确性。
4. 重新生成图形：`python scripts/build_visuals.py --render`。此开发命令需 Python、Playwright 和 Chromium，技能使用无需这些依赖。

安装位置与发现方式参考 [OpenAI 官方技能文档](https://learn.chatgpt.com/docs/build-skills)。正式发布内容不包含测试环境配置、账号凭证或私人决策材料。
